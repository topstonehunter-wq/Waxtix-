**Waxtix** is a modern, feature-rich social media and content platform frontend designed with a sleek dark navy aesthetic. It integrates short video feeds, live news updates, direct messaging, profile management, and quick content uploading.

---

## 📱 Pages & Features Included

1. **Home Screen (Video Feed):** 
   * Short-form vertical video viewer with duration badges (`60s`)[span_0](start_span)[span_0](end_span).
   * Floating action buttons for Likes (`12.4k`), Comments (`88`), Shares (`320`), and Downloads[span_1](start_span)[span_1](end_span).
   * Creator tag (`@alpine_journeys`), caption area, and an interactive Follow button[span_2](start_span)[span_2](end_span).
2. **News Feed Screen:**
   * Category filter tabs (*All*, *Local*, *World*, *Sports*)[span_3](start_span)[span_3](end_span).
   * Informational article/video cards containing timestamps, read counts, and media previews[span_4](start_span)[span_4](end_span).
3. **Chat & Messages Screen:**
   * Active conversation tabs (*Following*, *Friends*, *Status*)[span_5](start_span)[span_5](end_span).
   * Direct message previews with online status indicators[span_6](start_span)[span_6](end_span).
   * Inline interactive message bubbles, media attachments, and voice note player widgets (`0:12`)[span_7](start_span)[span_7](end_span).
4. **Profile & Account Drawer Screen:**
   * User bio, statistics (*Following*, *Followers*, *Viewers*)[span_8](start_span)[span_8](end_span), and video tabs (*My videos*, *Uploads*)[span_9](start_span)[span_9](end_span).
   * Slide-out navigation drawer featuring account settings (*Change languages*, *Help Center*, *Manage account*, *Settings*), sign-in methods (*Telephone*, *Google*, *Email*), and code verification[span_10](start_span)[span_10](end_span).
5. **Upload Screen:**
   * Dedicated file dropzone card designed for publishing short-form video files.

## 🛠️ Tech Stack

* **HTML5** for structure.
* **Tailwind CSS** for responsive design and utility styling.
* **FontAwesome** for scalable icons.
